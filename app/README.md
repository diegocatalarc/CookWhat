# App: ¿Qué cocino hoy?

App web instalable (PWA) hecha con React + TypeScript + Vite.

## Comandos

```bash
npm install      # instalar dependencias (una vez)
npm run dev      # abrir la app en modo desarrollo
npm test         # correr las pruebas
npm run lint     # revisar el código
npm run build    # generar la versión para publicar (carpeta dist/)
```
